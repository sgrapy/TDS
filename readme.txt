# Taverne des Scores

Bienvenue dans **Taverne des Scores**, un site mobile et desktop pour gérer facilement les scores de vos jeux de cartes et de société !

## Version
- **v1.0**

## Description
- Gestion des scores pour Belote, Coinche, Tarot, Tarot Africain, Rami, Skyjo, Papayou.
- Saisie manuelle ou automatique selon les jeux.
- Catégories de jeux (Classiques / Modernes).
- Profils de règles (Détente, Compétition, Officiel).
- Thèmes colorés et personnalisables.
- Sauvegarde automatique et export/import JSON.
- Animations légères : paillettes, Matrix, Zelda...
- Barre de progression suivant les scores.
- Affichage dynamique du gagnant avec médaille.

## Utilisation
1. Ouvrir `index.html`.
2. Choisir un jeu.
3. Configurer la partie (options et profil de règles).
4. Saisir les scores manche par manche.
5. Admirer la progression et déclarer le vainqueur !

## Technologies
- HTML5
- CSS3 (animations, thèmes dynamiques)
- JavaScript pur (aucun framework)
- localStorage pour la sauvegarde locale
